# Changelog

## 0.2.0 - 2026-08-19

### Added

- Add opt-in semantic icons through `showsIcon`, while keeping text-only toast presentation as the default.

### Changed

- Align the capsule with system transient presentation: no shadow, tighter padding, and regular-weight titles.
- Keep the existing zero-configuration placement, animation, duration, pass-through interaction, accessibility announcement, and per-screen capacity contracts.

## 0.1.1 - 2026-08-16

- Remove the unused Xcode scaffold from the Swift Package release.

## 0.1.0 - 2026-08-16

- Initial public release of the house-standard transient feedback package.
